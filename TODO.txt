# Structure review

## Expose the hosts as checks
`nix fmt` works now; `nix flake check` still builds nothing.
Fix: expose both host toplevels as `checks` -- that catches a new file not
`git add`ed before a rebuild does.

## wpctl is called by name but never provided
config.kdl binds the volume keys to wpctl; niri's runtimePkgs has no
wireplumber. Works here only because services.pipewire puts it on the system
path -- dead keys for anyone running `nix run .#niri`.
Fix: add pkgs.wireplumber to runtimePkgs in desktop/niri/package.nix.

## An efi-boot module
The boot loader + stateVersion block is repeated in all three hosts.
Fix: a small `efi-boot` module for the boot block.

## laptop-vm on aarch64 is an x86_64 derivation
`perSystem = _:` ignores system, so packages.aarch64-linux.laptop-vm has the
same drvPath as the x86 one. Wrong under `nix flake check` on ARM, and VM
runners are not packages by our own definition.
Fix: move claude-vm and laptop-vm to `apps`, or guard on system.

## A shared palette would still cover seven of ten consumers
The no-palette argument only rules out config.kdl, pinentry.rasi and the rmpc
theme.ron. The rest are Nix.
Fix: `flake.lib.palette` as a plain attrset, plus functions for the RRGGBBAA
and rgba() spellings. Cuts the "changing a color means editing" list from ten
files to four, and kills the two hexes that hide from grep. No substitution,
no new input.

## config.kdl is 696 lines, 230 of them real
The rest is niri's shipped example comments.
Fix: trim to what we actually set. Makes the open laptop/desktop monitor
question visible.

## Doc drift in CLAUDE.md
- Says niri gets `"config.kdl".path`; package.nix uses `.content = builtins.readFile`.
  Switch the code to `.path`, which is what the doc describes and is better.
- The bar table is missing Dnd.qml, DndWidget.qml, SysInfo.qml, SystemWidget.qml.
